One line of weather, 125 characters, for Bramblewick — a city that does not exist. It keeps the rhythm of a real broadcast forecast (morning fog, clearing by noon) and bends it with one concrete commuter detail: the 8:10 bus, so lost in the fog it is legally a rumour, and sunshine warm enough to be forgiven for it.

> Bramblewick: morning fog so thick the 8:10 bus is legally a rumour, clearing by noon into sunshine warm enough to forgive it.

## Run it

```sh
python3 main.py
```

Writes the forecast to `<MAKEFUN_OUTPUT_DIR>/entry.txt` (default
`/output/entry.txt`). Standard library only, deterministic, no network.
The program reads the file back and verifies it against the line it wrote.
